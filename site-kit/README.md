# Site yapım kiti

Yeni site, mağaza ya da tanıtım sayfası yaparken kullanılacak beceriler ve araçlar.

| Beceri | Ne yapar |
|---|---|
| `site-building-kit` | Başlangıç noktası: yığın seçimi, en çok yıldızlı GitHub projeleri, test ve teslim akışı |
| `design-taste-frontend` | "Yapay zekâ yapmış gibi" durmayan şirket/ürün/mağaza siteleri (Leonxlnx/taste-skill, MIT) |
| `scroll-craft` | Kaydırınca hareket eden sahneler, katmanlı açılış, imza hareketi (nateherk-design) |
| `impeccable` | Hazır tasarımı cilalar, eleştirir, denetler (polish, critique, audit, bolder…) (pbakaus/impeccable) |
| `frontend-design`, `theme-factory`, `canvas-design`, `algorithmic-art`, `web-artifacts-builder`, `webapp-testing` | Anthropic resmi becerileri: özgün arayüz, tema, afiş, üretken görsel, React artifact, Playwright testi |
| `copywriting`, `copy-editing`, `cro`, `offers`, `popups`, `signup`, `marketing-psychology`, `product-marketing` | Satış metni ve dönüşüm (coreyhaines31/marketingskills) |
| `seo-audit`, `ai-seo`, `schema`, `site-architecture` | SEO, yapay zekâ aramaları, yapılandırılmış veri, sayfa yapısı |
| `conversion-tracking`, `ab-testing`, `emails` | Ölçüm, A/B testi, e-posta akışları |
| `../skills/*` | Bu reponun genel becerileri: arayüz, performans, güvenlik, yayın, planlama… |

Kaynaklar ve lisanslar: `VENDORED.md`.

Kurulum (her yeni oturumda bir kez):

```bash
bash site-kit/install.sh
```

`tools/shopify-preview/` TEYEL Shopify temasında kullanılan önizleme, Theme Check, ekran görüntüsü araçlarıdır.
